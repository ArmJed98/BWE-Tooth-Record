Feature — Historical Browser

ดูข้อมูลย้อนหลังของแต่ละวัน

ทุกฟอร์มด้านบนมีปุ่ม 📅 ดูข้อมูลย้อนหลัง ที่มุมขวาบน — กดแล้วเปิดปฏิทินให้เลือกวัน ระบบจะเติมฟอร์มด้วยข้อมูลของวันนั้นแบบ อ่านอย่างเดียว พร้อมปุ่ม แก้ไข ถ้าต้องการเปลี่ยน

ตัวอย่างการใช้งาน

3 สถานะ · Add / View / Edit
  1. Add (default) — เปิดฟอร์มมา ทุกช่องว่าง วันที่ = วันนี้ กด บันทึกเพิ่มรายการใหม่
  2. 📅 View — กดปุ่มปฏิทิน → เลือกวันที่มีจุดเขียว → ฟอร์มเติมข้อมูลอัตโนมัติ ทุกช่องเป็น readonly มี โหมดดู ปรากฏข้าง h2
  3. ✎ Edit — กดปุ่ม แก้ไข → ปลดล็อคช่อง แก้แล้วบันทึกทับ

สัญลักษณ์ในปฏิทิน

  • 15วันนี้
  • 10วันที่กำลังดู
  • 12มีข้อมูลบันทึกไว้
  • 05ยังไม่มีข้อมูล
